# Team

Generated by `armadai link` from `.armadai/`: edit the sources, not this file.

## Agents

- `architect`
- `dev`
- `lead` (coordinator, the default primary agent)
- `reviewer`

Free agents, delegable from any agent: `explore`.

## Flows

Delegation follows the transitions below, enforced by OpenCode permissions (`policy.delegation: strict`).

### Flow `deliver`

A request is designed, implemented, then reviewed until approved

Start: `design`

Steps:

- `build` (agent `dev`)
- `design` (agent `architect`)
- `review` (agent `reviewer`, states: approved, rejected)

Transitions:

- `design` -> `build`
- `build` -> `review`
- `review` -> `build` when `rejected`
