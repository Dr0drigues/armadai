# Harnais e2e déterministe — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** Un banc e2e déterministe qui lance le vrai binaire `armadai run … --json` contre un provider stub (`fake-claude`), pilote chaque cas par un **case file déclaratif** (réponses + assertions), et produit un **rapport HTML pondéré**. Livrable = la PR harnais avec des **baselines vertes** (direct/hierarchical/blackboard/ring/nested).

**Architecture:** `fake-claude` (bin Rust, moteur de règles, émet du claude stream-json) est mis sur le `PATH` en tant que `claude` par le runner ; `armadai` (provider `claude` → CLI → shell-out) l'atteint. Un runner Rust générique (`assert_cmd` + `tempfile`) découvre les `tests/e2e/cases/*.yaml`, monte un tempdir (project + agents), exécute, parse le JSONL, évalue le bloc `expect`, agrège en rapport.

**Tech Stack:** Rust edition 2024 ; dev-deps `assert_cmd`, `tempfile`, `serde_yaml_ng` (déjà présent), `schemars` (dev) ; `serde_json`.

## Global Constraints

- Base = `origin/release/1.0.0` (@ d97d460 — inclut le fix #217 system_prompt). Branche `feat/e2e-harness`, PR vers `release/1.0.0`.
- **Zéro réseau, zéro LLM** : tout est déterministe (fake-claude), DB in-memory (`init_embedded`), tempdirs jetables.
- Le fake est invoqué **en tant que `claude`** (le provider config des agents de test = `provider: claude` → command `claude` ; le runner shadow `claude` sur le `PATH` avec `fake-claude`). Le **parsing du provider est dispatché par le nom de commande `claude`** → le fake DOIT émettre du **claude stream-json** (cf. format ci-dessous).
- **#217 acquis** : le provider CLI transmet désormais `system_prompt` en préfixe (`<system>…</system>\n\n<task>`), donc l'argv reçu par le fake contient le system prompt de l'agent (et le marqueur `FAKE_AGENT_ID`).
- Clippy `-D warnings` en `--features tui`, `--features tui,providers-api`, `--features tui,storage` + `cargo fmt`. Les ~969 tests existants restent verts.
- `fake-claude` = `[[bin]]` **toujours compilé** (léger, pas de dep lourde) pour que `env!("CARGO_BIN_EXE_fake-claude")` soit dispo dans les tests sans jongler avec les features.
- Les cas de BUG (ring/quiet/budget) ne sont PAS dans cette PR (ils sont sur la branche Lot 4). Ici : infra + **baselines vertes** uniquement.

### Format claude stream-json que le fake émet (vérifié dans `json_runner.rs:145-199`)
Pour un tour réussi, sur stdout, une ligne par event :
```
{"type":"assistant","message":{"content":[{"type":"text","text":"<REPONSE>"}]}}
{"type":"result","subtype":"success","is_error":false,"result":"<REPONSE>","total_cost_usd":<COST>,"usage":{"input_tokens":<TIN>,"output_tokens":<TOUT>},"modelUsage":{"<MODEL>":{"outputTokens":<TOUT>}}}
```
Le provider accumule le `content` depuis l'event `assistant` (`Delta`), et lit model/tokens/cost depuis l'event `result`. `<REPONSE>` = la réponse scriptée (avec ses marqueurs protocole `@…`/`ACTION:`/`CONFIDENCE:` selon le cas).

### Task 1: `fake-claude` — moteur de règles + émission claude stream-json

**Files:** Create `src/bin/fake-claude.rs`; modify `Cargo.toml` (`[[bin]]`). Test: inline `#[cfg(test)]` + a couple of scenario fixtures.

**Interfaces produces:**
- Un binaire qui : lit `FAKE_SCENARIO` (chemin d'un YAML `{ rules: [ { match: {agent?, call?, prompt_contains?}, respond: String, tokens_in?: u32, tokens_out?: u32, cost?: f64, model?: String, latency_ms?: u64, exit_code?: i32 } ] }`), lit son **dernier argv** = le prompt composé, en extrait l'agent via `FAKE_AGENT_ID:\s*(\S+)`, incrémente un compteur d'appels par agent dans `FAKE_STATE_DIR/<agent>.count`, évalue les règles (première qui matche : `agent` égal, `call` == compteur courant, `prompt_contains` sous-chaîne), et émet le claude stream-json de la réponse choisie (assistant + result), applique `latency_ms` (via `std::thread::sleep`), sort avec `exit_code`.
- Réutilise `serde`/`serde_yaml_ng`/`serde_json` (déps du crate). Fonctions pures testables : `select_response(scenario, agent, call, prompt) -> &Rule`, `emit_claude_jsonl(rule) -> String`.

```rust
#[cfg(test)]
mod tests {
    use super::*;

    fn scen() -> Scenario {
        Scenario { rules: vec![
            Rule { match_: Match { agent: Some("t-coord".into()), call: Some(1), prompt_contains: None },
                   respond: "@t-a: go".into(), tokens_in: Some(10), tokens_out: Some(3), cost: Some(0.001), model: Some("m".into()), latency_ms: None, exit_code: None },
            Rule { match_: Match::default(), respond: "ok".into(), tokens_in: None, tokens_out: None, cost: None, model: None, latency_ms: None, exit_code: None },
        ]}
    }

    #[test]
    fn selects_by_agent_and_call() {
        let s = scen();
        let r = select_response(&s, "t-coord", 1, "prompt");
        assert_eq!(r.respond, "@t-a: go");
        // fallback catch-all for another agent
        assert_eq!(select_response(&s, "t-x", 1, "p").respond, "ok");
    }

    #[test]
    fn emits_parseable_claude_jsonl() {
        let r = &scen().rules[0];
        let out = emit_claude_jsonl(r, "t-coord");
        // two lines: assistant (content) + result (metrics)
        assert!(out.contains(r#""type":"assistant""#));
        assert!(out.contains(r#""type":"result""#));
        assert!(out.contains(r#""text":"@t-a: go""#));
        assert!(out.contains(r#""input_tokens":10"#));
        assert!(out.contains(r#""total_cost_usd":0.001"#));
    }

    #[test]
    fn extracts_agent_id_from_prompt() {
        let p = "<system>\nyou are X\nFAKE_AGENT_ID: t-coord\n</system>\n\ntask";
        assert_eq!(agent_id_from_prompt(p), Some("t-coord".to_string()));
        assert_eq!(agent_id_from_prompt("no marker"), None);
    }
}
```

### Task 2: Case file format + schema (serde + schemars)

**Files:** Create `tests/e2e/mod.rs` (ou `src/e2e/` — choisir un emplacement compilé par les tests ; recommandé : un module `tests/e2e/case.rs`) avec les types ; modify `Cargo.toml` (`[dev-dependencies] schemars`, `assert_cmd`, `tempfile`). Test: fixtures YAML.

**Interfaces produces:**
- `struct CaseFile { name: String, weight: u32, #[serde(default)] allow_fail: bool, setup: Setup, fake: FakeSpec, expect: Expect }` (+ sous-types), dérivant `serde::Deserialize` + `schemars::JsonSchema`. (`allow_fail` défaut `false` — un cas 🔴 connu/toléré ne fait pas échouer la suite.)

  - `FakeSpec { rules: Vec<Rule> }` (réutilise le `Rule`/`Match` de Task 1 — factorise dans un module partagé `e2e::scenario` importé par le bin ET les tests, OU redéfinis identiquement et documente).

- `fn load_case(path) -> anyhow::Result<CaseFile>` (serde_yaml_ng) ; `fn case_json_schema() -> String` (schemars) pour émettre `docs/e2e-case.schema.json`.

### Task 3: Runner générique (assert_cmd + tempdir)

**Files:** Create `tests/e2e/harness.rs` + `tests/e2e/runner.rs`.

**Interfaces:**
- Consumes: `CaseFile` (T2), `fake-claude` (T1, via `env!("CARGO_BIN_EXE_fake-claude")`).
- Produces:
  - `fn run_case(case: &CaseFile) -> CaseOutcome` : (a) `tempfile::tempdir()` ; (b) écrit `armadai.yaml` (selon `setup.pattern`/agents — orchestration config pour hier/blackboard/ring, rien pour direct) + `agents/<a>.md` pour chaque agent (avec `provider: claude`, `model: <concret>`, et un system prompt contenant `FAKE_AGENT_ID: <a>` + les instructions minimales) ; (c) écrit le scénario `fake.rules` dans `<tmp>/scenario.yaml` ; (d) crée `<tmp>/bin/claude` = symlink/copie de `CARGO_BIN_EXE_fake-claude` ; (e) `assert_cmd::Command::cargo_bin("armadai")` avec `env("PATH", "<tmp>/bin:"+PATH)`, `env("FAKE_SCENARIO", …)`, `env("FAKE_STATE_DIR", …)`, args `run <coordinator/agent> <input> <flags...>`, `current_dir(tmp)` ; capture stdout/stderr/exit.
  - `fn evaluate(case, stdout, exit) -> CaseOutcome` : parse le JSONL (chaque ligne = un `serde_json::Value` avec `t`), vérifie `exit_code`, présence + ordre partiel des `events` (chaque `ExpectedEvent` doit apparaître, dans l'ordre relatif ; champs = sous-ensemble), `event_counts`, `invariants` (fonctions nommées : `agent_start_end_symmetric`, `prov_model_non_empty`, `single_result`, …), et `storage` si présent.
  - `struct CaseOutcome { name, weight, passed: bool, allow_fail: bool, expected, observed, diffs: Vec<String> }` (Default derivable pour les tests ; `allow_fail` recopié du `CaseFile`).
