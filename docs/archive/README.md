# Archive

Historical documents of the pre-refocus ArmadAI (execution engine, TUI, web, shell, audit,
registry). They describe commands, crates and features that no longer exist in the product.

The code they describe is recoverable from commit `9b02047` (tag `pre-v1-declaratif` once
pushed). Not maintained: links inside these files may point at paths that have moved or been
removed, and no statement here should be read as describing the current product.

For the current state, start from the [README](../../README.md) and the
[step 0 spec](../superpowers/specs/2026-10-09-step0-retrait-surfaces-design.md).

Layout:

- `wiki/`: former wiki pages (orchestration guide and reference, `armadai audit`, migration
  v0 to v1).
- `design/`, `proposals/`: design notes and proposals of the execution era.
- `superpowers/specs/`, `superpowers/plans/`: specs and plans of the execution era, plus the
  gaveldrop migration logs.
- `PARALLEL_DELEGATION.md`, `v1-backlog.md`, `unsafe-audit-2026-04-01.md`: standalone notes.
